# Xarxa Reviews — Responsive

Interfaz adaptable a ordenador, iPhone y Android. Incluye resumen, reseñas con filtros, detalle y respuesta en modo demo, insights y sección de conexión Google.

## GitHub
Crea un repositorio y sube estos tres archivos (`index.html`, `manifest.webmanifest`, `sw.js`) más este README a la raíz. Activa GitHub Pages en Settings → Pages → Deploy from a branch → `main` → `/root`.

## Importante
Las reseñas son datos de demostración, no sincronización en directo. La acción «Aprobar» solo cambia el estado local; no publica en Google. El botón Google requiere backend OAuth en HTTPS; GitHub Pages no ejecuta FastAPI ni guarda secretos. No subas tokens, credenciales ni `.env`.
